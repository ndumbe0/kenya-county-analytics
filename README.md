# Personal Projects

Three production-quality, showcase-ready full-stack data applications with ML capabilities.

## Projects

### [PubMed Explorer](pubmed-explorer/)
Exploring PubMed articles with full-text search, facets, and ML insights.
- Tech: FastAPI, SQLAlchemy, SQLite, FTS5, React, Vite, TypeScript, Tailwind, Recharts

### [SaaS Intel Hub](saas-intel-hub/)
Micro-SaaS ideas database with ML-powered analysis and predictions.
- Tech: FastAPI, SQLAlchemy, SQLite, React, Vite, TypeScript, Tailwind, Recharts

### [Mortality Explorer](mortality-explorer/)
Mortality data exploration with time series analysis and forecasting.
- Tech: FastAPI, SQLAlchemy, SQLite, React, Vite, TypeScript, Tailwind, Recharts

## Quick Start
Each project has its own `run.ps1` for local development. See individual READMEs for details.
